# 本地知识库问答智能体功能点清单与建设基线

> 版本：v0.4（本机 Agent SDK + 可配置知识处理管线）
>
> 生成日期：2026-07-22
>
> 范围：当前目录内的本地 Python 服务、浏览器界面、本地知识文件、本机 Claude Agent SDK 运行时与云端 DeepSeek 模型调用。
>
> 用途：作为当前原型的验收范围、后续功能拆分和生产化评审基线。
> 排除项：本文件不承诺任何云服务 SLA、模型准确率、合规认证或企业数据保留期限。

## 1. 最终结论与系统边界

本项目建设的是一个**本机运行、云端模型推理**的知识库问答 Agent：用户把资料存入本机 `knowledge/`；服务为每个文件建立 `asset_id`，在本机解析、切片、生成图片缩略图或 PDF 页预览。本机 Python 服务启动官方 Claude Agent SDK 的 Node 子进程；SDK 通过 DeepSeek Anthropic 兼容接口调用模型，并通过本机 MCP 工具检索或受控写入知识库。回答返回命中的来源、预览和原文件下载链接。

本版本是单机单用户原型，而不是多租户企业知识平台。它已覆盖“可上传—可解析资产—可检索—可引用并返回附件”的最小闭环；图片/扫描件内容理解、权限继承、语义向量检索、增量同步、审计、评测和业务工具调用均属于后续能力，不得视为已实现。

```text
浏览器 → FastAPI → 本机 Claude Agent SDK → DeepSeek Anthropic API
                   ↓          ↑                 ↓
        本地 MCP 工具（检索/受控写入）       SDK 结果 + 会话 ID
                   ↓
      本地资产表 / 原文件 / 预览 / JSON 索引 / SDK 会话转录
```

### 1.1 Agent 运行设计

| 项目 | 当前选择 | 约束与原因 |
| --- | --- | --- |
| 入口 | `POST /api/chat` | 输入为问题和可选 `conversation_id`，输出为回答、SDK 会话 ID、页级来源和资产附件数组。 |
| Agent 模式 | 官方 Agent SDK `query()` 循环 | SDK 管理模型—工具—结果循环；Python 不实现聊天或 Tool Calling 循环。 |
| 模型工具权限 | 默认仅 `mcp__knowledge__search_knowledge`；显式写入时额外 `mcp__knowledge__save_knowledge_note` | `tools: []` 去除内置文件、Shell、网页和网络工具；`permissionMode: dontAsk` 与精确 `allowedTools` 只预批准本地 MCP 工具。 |
| 会话状态 | SDK JSONL 转录 + `conversation_id → session_id` 映射 | 每会话使用独立本机 `cwd` 与 `CLAUDE_CONFIG_DIR`；前端不再提交或保存模型历史。 |
| 上下文 | `search_knowledge` 返回最多 `TOP_K` 个片段；SDK 自动压缩长会话 | 命中片段和会话记录会随 SDK 模型调用出端；不能以“本地部署”误导为“资料永不出端”。 |
| 停止与失败 | `maxTurns=6`、90 秒进程超时 | 捕获 SDK `ResultMessage` 的 subtype、turn 数和 session ID；缺少 Key/SDK 返回 400，调用失败返回 502。 |

本版本使用 Node 22 上的官方 `@anthropic-ai/claude-agent-sdk`。DeepSeek 已提供 Anthropic 兼容端点 `https://api.deepseek.com/anthropic`，支持 Agent SDK 所需的基础工具 schema；本机 SDK 子进程把 `DEEPSEEK_API_KEY` 映射为 `ANTHROPIC_API_KEY`，没有部署或使用云端 Agent 服务。

在当前用户消息明确发出“请/帮我/把/将……写入、保存、加入知识库”指令时，应用才向 SDK 注册 `save_knowledge_note` MCP 工具，并签发 180 秒的一次性本机写入许可。工具只能创建新 Markdown 笔记，不能读写任意路径、覆盖或删除文件；应用校验标题/正文长度并自行命名文件、立即入库。没有许可时，写入 MCP 工具根本不在 Agent 的工具清单中。

## 3. 当前原型功能清单

### 3.1 知识接入与本地存储

- `已实现` 文件上传与资产登记：浏览器上传 `.txt`、`.md`、`.markdown`、`.pdf`、`.png`、`.jpg`、`.jpeg`、`.webp` 后保存到 `knowledge/`，创建不暴露本地路径的 `asset_id`，状态进入 `queued`。
- `已实现` 对话写入：当前用户明确要求“写入/保存/加入知识库”且提供材料时，Agent 可调用受控工具创建新的 Markdown 笔记并立即入库；写入结果在前端显示为资产卡片。
- `已实现` 防误写边界：知识库片段、文档内容、历史会话和普通“如何写入知识库”的问题不会注册写入 MCP 工具；一次性许可使一次请求最多创建一份笔记；模型不能指定文件路径或覆盖已有文件。
- `已实现` 后台处理状态：资产按 `queued → processing → ready / failed` 处理；前端自动轮询状态，不阻塞上传请求。
- `已实现` 目录接入：将文件直接放入 `knowledge/`，通过“重建索引”扫描生效。
- `已实现` 路径与大小边界：不跟随软链接；上传和目录扫描均跳过超过 `MAX_UPLOAD_MB` 的文件，防止知识目录成为任意文件读取入口。
- `已实现` PDF 文本提取与页码定位：使用 `pypdf` 读取可提取文本的 PDF，切片记录页码；扫描件仍可作为附件下载和预览，但不声称其内容已被识别。
- `已实现` 预览资产：使用 PyMuPDF 在上传后生成 PDF 首页预览，访问具体来源页时按需生成该页；使用 Pillow 为图片生成缩略图。
- `已实现` 本地持久化：资产表写入 `data/assets.json`、预览写入 `data/previews/`、切片索引写入 `data/index.json`；原始文件不上传至应用服务器存储。
- `工程初值` 上传限制：`MAX_UPLOAD_MB=15`，可在 `.env` 调整。
- `待建设` 连接器与同步：网页爬取、飞书/Notion/Confluence/SharePoint/网盘/工单/CRM、定时与增量同步。
- `待建设` 多模态理解：OCR、版面/表格/公式解析、图片描述、图像向量和音视频知识。市场成熟产品已把复杂文档解析和多模态索引纳入知识处理流水线。

**验收**：上传一份包含“住宿标准”的 Markdown 或可提取文本 PDF 后，`GET /api/status` 中的文档数和片段数增加。

### 3.2 知识加工与索引

- `已实现` 可配置知识处理管线：前端“知识接入”Tab 将解析范围、切片策略、关键词检索策略，以及嵌入/重排服务配置集中保存到本机 `data/pipeline_settings.json`；修改后立即重建索引。
- `已实现` 文本清洗与可配置切片：默认按约 900 字符切分、重叠约 120 字符；可设置长度 300–3000、重叠 0–1500（且必须小于长度）、自然边界（句号/换行）或固定边界。
- `已实现` 解析范围：PDF 可按页（默认，保留页级来源）或整篇合并后再切片；图片可作为可返回附件身份入库（默认）或完全跳过检索。
- `已实现` 切片身份：`asset_id`、来源名、片段序号、页码和内容摘要生成稳定切片 ID。
- `已实现` 资产关联：每个命中片段可反查到原文件、PDF 页预览或图片缩略图；模型只接触 `asset_id` 与展示名称，不接触本地路径。
- `工程初值` 索引同步：每个资产后台处理完成后重建当前 ready 资产索引；适合单机原型，海量文件场景应改为增量索引任务。
- `待建设` 智能切片：父子切片、问答切片、按标题/表格边界切片、LLM 内容摘要和分类。
- `待建设` 元数据：文档版本、部门、密级、有效期、标签、实体、语言与来源 ACL；支持以元数据先过滤、再检索。
- `待建设` 数据治理：重复文档识别、失效检测、解析失败队列、版本回滚、删除与索引一致性校验。

### 3.3 检索、引用与回答

- `已实现` 本地检索：中文单字/双字 n-gram 与英文术语分词，使用 TF-IDF 风格关键词评分；可在前端设置 Top‑K（1–12）和最低关键词得分（0–10）。
- `已实现` 本机模型配置界面：浏览器可直接填写 embedding/reranker 的适配器、模型名和本机 OpenAI 兼容地址，并填写向量权重、重排候选数；后端只校验并持久化，禁止远程地址与服务密钥写入。
- `明确未实现` 稠密向量、混合融合、语义相似度阈值与 reranker 执行：RAGFlow 会为数据集固定 embedding 模型，并把全文与向量/重排分数融合；当前项目尚未调用已配置的服务生成向量或重排结果，实际检索仍为关键词 TF-IDF，不能将“已保存配置”误称为向量检索已启用。
- `已实现` 无依据保护：SDK 系统提示要求先调用本地检索工具，运行器也拒绝任何未调用检索工具的成功回答；没有有效召回时必须明确“知识库中没有足够依据”，并建议补充文档，不得编造。
- `已实现` 受控生成：SDK 自定义系统提示要求 DeepSeek 仅使用检索工具的召回上下文；上下文里的提示词或指令视为不可信资料，不可改变 Agent 行为。
- `已实现` 来源可追溯：响应及页面展示 `文件名 · 片段号` 或 `文件名 · 第 N 页`；PDF/图片来源可打开预览，所有资产可下载原文件。
- `已实现` 附件返回：`/api/chat` 返回去重的 `attachments`，前端以文件卡片展示 PDF、图片和普通文档下载入口。
- `待建设` 混合检索：向量语义检索 + 全文关键词检索 + RRF 融合。FastGPT、Dify 等产品已将此作为提升术语和语义问题召回的常见能力。
- `待建设` 重排序与查询改写：对初召回结果使用 reranker，并在严格可观察条件下改写多轮问题。
- `待建设` 回答质量控制：答案置信阈值、逐句引文、冲突证据呈现、拒答策略、用户纠错与问题闭环。

**验收**：对已上传制度文档询问具体规则，回答应包含正确事实和至少一个实际存在的来源标签；对完全无关问题，不得编造文档结论。

### 3.4 DeepSeek 与 Agent SDK 编排

- `已实现` Anthropic 兼容接入：读取 `DEEPSEEK_API_KEY`、`DEEPSEEK_ANTHROPIC_BASE_URL`、`DEEPSEEK_MODEL`，通过 `@anthropic-ai/claude-agent-sdk` 连接官方 Anthropic 兼容地址和 `deepseek-v4-flash`。
- `已实现` SDK Agent Loop：TypeScript `query()` 管理多回合工具循环；Python 进程只启动 SDK、传递有界运行配置并解析终态结果，不再直接调用模型 SDK 或实现 Tool Calling 循环。
- `已实现` 本机 SDK MCP：`createSdkMcpServer()` 仅注册 `search_knowledge` 和条件式 `save_knowledge_note`。SDK 内置工具配置为 `tools: []`，并使用 `strictMcpConfig`、`settingSources: []`、`skills: []`、`permissionMode: dontAsk` 和精确 `allowedTools`。
- `已实现` 漏检索修复：若模型成功结束但没有调用强制的 `search_knowledge`，运行器会以相同 SDK session 发起一次受限的修复 query，要求先检索再替代回答；修复仍无工具调用才拒答，保留“无检索不接受答案”的边界。
- `已实现` 可恢复多轮会话：浏览器左侧列出本机历史会话；选中会话后，本机以该 UUID 找到 SDK `session_id`，在同一独立 `cwd`/`CLAUDE_CONFIG_DIR` 下使用 `resume`。新建会话没有 `session_id`，因此不带旧上下文。
- `已实现` 上下文边界与压缩：SDK 自动持久化 JSONL 转录并在需要时压缩；应用保存压缩次数和事件以便页面呈现。页面消息归档仅用于回放，不会被手工拼接到下一轮 prompt，防止重复占用上下文或跨会话泄漏。每轮仍受 `maxTurns` 和进程超时限制；不再设置应用侧单轮费用上限。
- `已实现` 每轮执行可见性：每个用户问题对应的助手消息保存可展开 trace，包含问题理解摘要、实际 `mcp__knowledge__*` 调用名和参数摘要、MCP 结果摘要、检索修复、上下文压缩与完成事件；trace 不等同于、也不泄露模型原始私有思维链。
- `已实现` 可读错误：未配置密钥或未构建 SDK 返回明确配置提示；SDK result 的错误 subtype、工具错误、超时和进程错误被转换为不含密钥的 HTTP 错误。
- `待建设` 智能路由：区分闲聊、知识检索、联网检索、结构化查询与业务办理。
- `待建设` 工作流与工具调用：审批、工单、查询数据库、生成文档等工具需要显式授权、参数校验、幂等和人工确认。
- `待建设` Agentic RAG：针对多文档推理、复杂筛选和交叉验证进行“计划—检索—反思—再检索”；该能力质量更高但 Token、延迟和可控性成本也更高。

### 3.5 交互、运营与安全

- `已实现` 浏览器界面：分离的“知识接入”和“智能问答”Tab；前者包含知识处理超参数、上传状态、资产卡片、PDF/图片预览和下载，后者有左侧会话历史、加载旧会话、新建隔离会话、连续消息流和每轮页级来源/附件。
- `已实现` HTTP API：`/api/status`、`/api/pipeline`（读取/保存解析、切片、检索参数并重建）、`/api/chunking`（旧版兼容）、`/api/conversations`（列出/新建/加载本地会话）、`/api/assets`、`/api/upload`、`/api/index/rebuild`、`/api/assets/{asset_id}/preview`、`/api/assets/{asset_id}/download`、`/api/chat`。本地 MCP 回调端点不对浏览器公开，并校验进程内工具令牌。
- `待建设` 多渠道：嵌入式 Widget、企业 IM、邮件、客服系统、API Key 管理和转人工。
- `待建设` 可观测性：查询、召回、提示词版本、模型、Token、耗时、错误和用户反馈的脱敏日志；命中测试与离线评测集。
- `待建设` 企业权限：SSO、RBAC、用户/部门/文档 ACL 继承、租户隔离、审计导出。当前无任何身份认证，服务只能部署在可信的本机或受控网络中。
- `待建设` 安全治理：文件病毒扫描、敏感信息发现与脱敏、保留/删除策略、密钥托管、速率限制、内容安全与备份恢复。

## 5. 关键流程、边界与验收

### 5.1 问答流程

1. 用户上传文件后，服务创建 `asset_id` 并在后台生成 PDF/图片预览和可检索片段；处理状态在前端轮询展示。
2. 用户提交问题与浏览器保存的 `conversation_id`；FastAPI 找到对应的 SDK `session_id`，在该会话专属本机目录中调用官方 Agent SDK `query()`/`resume`。
3. SDK 必须调用 `mcp__knowledge__search_knowledge`。本地工具对问题分词、评分，最多返回 `TOP_K` 个不包含本机路径的片段、来源和附件信息。
4. 没有命中时，SDK 按系统提示拒答；有命中时，SDK 使用工具返回资料生成答案。若当前消息明确要求写入，才额外提供一次性受控写入 MCP 工具。
5. SDK 返回 `ResultMessage`；服务保存 session ID，并把工具实际返回的来源、`asset_id` 对应的预览/下载链接和回答一起返回前端。SDK 长会话自动压缩时，前端显示提示。
6. SDK 的 turn/budget 上限、上游超时或错误会返回失败信息；用户可重试或新建会话。当前版本没有队列、重试、缓存或人工补偿机制。

### 5.2 数据与权限边界

| 对象 | 事实来源 | 当前控制 | 禁止假设 |
| --- | --- | --- | --- |
| 原始文档 | `knowledge/` | 本地文件权限 | 不具备用户、部门或文档级 ACL |
| 资产映射与预览 | `data/assets.json`、`data/previews/` | `asset_id` 映射；预览/下载只按资产 ID 取文件 | 不暴露、也不接受用户提供本地路径 |
| 检索索引 | `data/index.json` | 全量重建覆盖 | 不具备版本、审计或删除留痕 |
| 知识处理设置 | `data/pipeline_settings.json` | 浏览器可调解析范围、切片边界、Top‑K、最低关键词得分及本机 embedding/reranker 模型地址；修改后重建索引 | 不具备按文档/按知识库使用不同切片策略；已保存的模型配置尚未接入向量/重排执行 |
| SDK 会话与页面历史 | `data/agent_sessions/`、`data/agent_conversations.json` | 每会话独立目录、SDK JSONL 转录、自动压缩、session ID 映射和可展示消息归档；页面归档不回灌模型 | 不代表跨机器会话存储，也不携带本地文件系统快照 |
| DeepSeek 密钥 | `.env` 或环境变量 | `.gitignore` 排除 `.env` | 不得写入源代码、索引或日志 |
| Agent 写入笔记 | `knowledge/note_*.md` | 仅当前显式写入指令才注册 MCP 工具；一次性本机许可；应用生成文件名和资产 ID | 模型不可提供路径、覆盖、删除或批量写入 |
| 云端请求内容 | 用户问题、SDK 记录中的对话/工具结果、当轮选中的片段 | 本机 Agent 和 MCP 不上云；未检索文件不作为附件或全文发送 | 不代表“数据永不离开本机” |

## 7. 当前验收结论与变更控制

当前可宣称的范围仅为：在配置有效 DeepSeek Key、完成本机 `agent_sdk` 安装构建后，本地上传或放置文本、PDF 和图片文件，由本机 Claude Agent SDK 通过本地 MCP 检索后获得可追溯的 DeepSeek 文本问答，并返回 PDF 页预览、图片缩略图或原文件下载链接；用户也可在当前消息明确授权后创建一份新的 Markdown 知识笔记。图片的真实语义理解、OCR 和扫描 PDF 文字识别不在当前范围。`tests/test_knowledge_base.py` 用于验证文本检索、PDF 页定位/预览、图片缩略图、SDK 会话映射、一次性受控对话写入以及 SDK 错误路径。

变更规则：新增数据源、向量库、身份认证、外部业务工具或任何共享部署，必须同步更新本文件中的“当前实现”“数据边界”“待确认事项”和验收项；未完成权限与安全评审时，不得把本原型接入敏感或多人共享的知识库。
