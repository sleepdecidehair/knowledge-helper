# 流式回答终止事件恢复设计

## 目标

当 SSE 连接自然结束但浏览器未收到 `done` 事件时，避免把已在服务端完整保存的本轮回答误报为“流式回答未正常结束”。本次只修改本地代码和本地构建产物，不部署服务器。

## 边界与判定

前端在流式请求开始前记录当前会话的消息数。若流结束时没有收到 `done`，前端读取同一会话；只有当服务端消息数至少比起点多两条，且最后一条为有正文的助手消息时，才将该已保存会话作为本轮成功结果加载。

服务端显式发送的 `error` 事件仍立即报错；会话未出现完整的一问一答时，继续显示现有的终止异常提示。不会重试流式请求，避免重复模型调用或重复写入历史。

## 验证

增加前端回归测试，覆盖恢复条件、显式错误不恢复以及缺失完整落库记录时仍报错。完成后运行前端测试、类型构建与后端全量测试，并只进行本地验证。
