# Security policy / 安全策略

## Supported versions / 支持范围

Security fixes are applied to the latest version on the `main` branch.

安全修复仅应用于 `main` 分支的最新版本。

## Reporting a vulnerability / 漏洞报告

Do **not** open a public issue containing API keys, documents, conversation data,
or proof-of-concept exploit details. Use GitHub's private vulnerability-reporting
feature for this repository when available, or contact the maintainer privately
through the GitHub account that owns the repository. Include reproduction steps,
impact, and the affected version. Rotate any exposed credential immediately.

请勿在公开 Issue 中包含 API Key、知识库文件、对话数据或漏洞利用细节。请优先
使用本仓库的 GitHub 私密漏洞报告功能；如该功能不可用，请通过仓库所有者的 GitHub
账号私下联系。请提供复现步骤、影响范围和受影响版本；若凭据泄露，请立即轮换。
